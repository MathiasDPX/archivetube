# Keybinds

Keyboard shortcuts help you save time on ArchiveTube.

| Keys             | Description                       |
| ---------------- | --------------------------------- |
| Arrow Left/Right | Seek 5 seconds                    |
| Arrow Up/Down    | Increase / decrease volume by 10% |
| Space            | Play / Pause                      |
| F                | Fullscreen                        |
| M                | Mute                              |
| Numbers 1 to 9   | Seek to 10% through 90%           |
| Number 0         | Seek to the beginning             |
