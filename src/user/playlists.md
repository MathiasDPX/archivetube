# Playlists

![Playlist screenshot](../assets/images/playlist_screenshot.png)

When you archive a playlist from YouTube, ArchiveTube will create a playlist for these videos. Currently, ArchiveTube doesn't supports creating playlist from the app itself, nor modifying these playlist. You can only delete and rename them.

If you open a video from a playlist, an "Up next" panel will be shown next to the description. It allows you to directly watch the next video without leaving the player.
